# Preserved upstream analysis: outside this release's acceptance scope

`compute_baseline_metrics.py` and `estimate_rct_did.py` are byte-for-byte copies from the commit in `UPSTREAM.json`. They have not been recalibrated or validated in this work. Their old file names, top-30% fields and provisional control specification must not be assumed compatible with the new uniform `results.csv` files.

No automatic conversion or analysis invocation is provided. The current validated workflow stops at experimental responses, parsed scores and flags. These scripts remain solely as upstream source material, not as a claim of statistical or numerical replication.
